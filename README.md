# Webdesign3

## Overview
Webdesign3 is an interactive frontend project that focuses on user interaction and dynamic UI behavior using JavaScript.

## Tech Stack
- HTML
- CSS
- JavaScript

## Development Style
This project was built using a **vibe coding** workflow, prioritizing visual feedback, interaction testing, and clean frontend logic.

## How to Run
Open the `index.html` file in your browser to interact with the project.
